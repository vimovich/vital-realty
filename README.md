# Vital Realty

Сайт агентства элитной недвижимости (демо). Статический HTML/CSS/JS, без сборки.

- index.html: главная, полноэкранные кадры (home.js, GSAP, WebGL)
- catalog.html + catalog.js: каталог с фильтрами
- property.html + property.js: страница объекта (?id=vr-101)
- services.html, about.html, contacts.html
- data.js: объекты, районы, брокеры (замените на реальные)
- site.css / site.js: общие стили и скрипты
